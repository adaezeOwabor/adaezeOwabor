### Featured Projects

#### 💳 [Fintech Transaction & Payment Flow Analytics](https://github.com/adaezeOwabor)
Evaluated transaction settlement rates, failure points, and user payment lifecycles across transactional datasets.
* Synthesized multi-table schemas to trace transaction success vs. gateway drop-offs.
* Designed automated SQL auditing queries to identify processing bottlenecks.
* Delivered executive KPI dashboards displaying throughput volume and merchant revenue drivers.
* **Stack:** SQL, Python, Power BI

#### 📦 [Supply Chain & Inventory Diagnostics](https://github.com/adaezeOwabor)
Conducted deep-dive inventory tracking to minimize lead-time latency and surface supplier performance anomalies.
* Modeled order replenishment cycles and dead-stock levels across historical distribution logs.
* Constructed DAX measures within Power BI to monitor fulfillment velocity in real time.
* Standardized raw supplier spreadsheets into normalized database tables.
* **Stack:** PostgreSQL, Excel, Power BI

#### 📉 [Customer Retention & Attrition Analysis](https://github.com/adaezeOwabor)
Analyzed customer behavioral metrics to identify indicators leading up to churn.
* Built automated data transformation workflows using Pandas to clean incomplete user records.
* Conducted cohort analysis to map customer drop-off curves across 30, 60, and 90-day intervals.
* Provided tactical recommendations for automated retention messaging.
* **Stack:** Python, Pandas, Matplotlib, Seaborn
